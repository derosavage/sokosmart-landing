# SokoSmart Calligraphic Identity

You are an expert calligrapher experienced graphics engineer. Your task is to create a logo one as a full name and the other for a banner. For SokoSmart. It should be in formats which can also be incorporated in UIUX content. It should be unique and it should follow these clor pallete:

Color	Hex Code	Best Use

🍉 Watermelon Red	#F4435E	Primary color, buttons, highlights

🌸 Watermelon Pink	#FF758F	Secondary accents, illustrations

🍃 Rind Green	#4CAF50	Secondary elements, icons

🌿 Deep Green	#216E39	Headings, contrast, borders

🤍 Pale Rind	#E8F5C8	Backgrounds, cards

🖤 Seed Black	#252525	Text, icons, outlines
